# Insurance Data Analysis – Power BI Project

## 📌 Project Overview
This project focuses on analyzing insurance data to gain insights into
policies, customers, premiums, and claims. The dataset is used in Power BI
to build interactive dashboards for business analysis and decision-making.

## 🗄️ Dataset Description
The dataset contains **10,004 records** with insurance-related information.
It includes customer demographics, policy details, premium values, coverage,
and claim information.

### 📑 Columns in the Dataset
- **PolicyNumber** – Unique identifier for each policy  
- **CustomerID** – Unique customer identifier  
- **Gender** – Customer gender  
- **Age** – Customer age  
- **PolicyType** – Type of insurance policy (e.g., Auto, Travel)  
- **PolicyStartDate** – Policy start date  
- **PolicyEndDate** – Policy end date  
- **PremiumAmount** – Premium paid for the policy  
- **CoverageAmount** – Total coverage amount  
- **ClaimNumber** – Claim identifier  
- **ClaimDate** – Date of claim (if any)  
- **ClaimAmount** – Amount claimed  
- **ClaimStatus** – Status of the claim (Approved, Pending, Rejected)

## 🛠️ Tools Used
- Power BI
- CSV Dataset
- SQL Server (for data storage and querying, if applicable)

## 📊 Key Analysis
- Policy type distribution
- Premium vs coverage analysis
- Claims amount and claim status analysis
- Customer demographic insights
- Trend analysis based on policy dates

## 🚀 How to Use
1. Open the Power BI `.pbix` file in Power BI Desktop  
2. Load the CSV dataset or refresh the data source  
3. Explore interactive dashboards and visuals  

## 📝 Notes
- Some policies may not have claims (ClaimAmount = 0)
- Missing claim dates indicate no claim filed
